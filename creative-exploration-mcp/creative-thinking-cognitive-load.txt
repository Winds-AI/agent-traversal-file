  ---
  Research Summary

  What creativity is psychologically

  Creativity is the ability to produce ideas that are both novel and
  appropriate. It arises from the interplay of three brain networks: the Default
   Mode Network (spontaneous associations, daydreaming), the Executive Control
  Network (evaluation, filtering), and the Salience Network (switching between
  the two). Highly creative people show stronger connectivity between these
  normally opposing networks.

  Where new ideas come from

  The major theories converge on one principle: connecting things that weren't 
  previously connected.

  - Bisociation (Koestler): perceiving a situation in two incompatible frames of
   reference simultaneously
  - Remote Associations (Mednick): creative people traverse associative networks
   faster and reach more uncommon nodes
  - Conceptual Blending (Fauconnier & Turner): two input spaces merge into a
  blended space with emergent properties that exist in neither input
  - Incubation (Wallas): stepping away lets fixation decay and unconscious
  processing find remote connections
  - Geneplore Model (Finke/Ward/Smith): alternate between generating rough
  "preinventive structures" with weak goal control and exploring/evaluating them

  Why this matters for AI

  Models are fixation machines. They predict the most probable next token, which
   means they converge on conventional solutions. Research shows:
  - AI replicates human fixation bias (80% of responses cluster in the same 3
  categories)
  - AI cannot distinguish original ideas from conventional ones
  - AI-assisted work is individually better but collectively more homogeneous
  (+10.7% convergence)

  The core design insight

  Your intuition maps directly onto established creativity mechanisms:
  Psychological Mechanism: Defocused attention
  Your Tool Design: Send minimal context to external models (removes "focus")
  ────────────────────────────────────────
  Psychological Mechanism: Remote associations
  Your Tool Design: Different models provide associations from different "minds"
  ────────────────────────────────────────
  Psychological Mechanism: Incubation
  Your Tool Design: Main agent steps back, lets other models process
  ────────────────────────────────────────
  Psychological Mechanism: Constraint relaxation
  Your Tool Design: External models don't inherit the main agent's assumptions
  ────────────────────────────────────────
  Psychological Mechanism: Bisociation
  Your Tool Design: Main agent combines its frame with external models' frames
  ────────────────────────────────────────
  Psychological Mechanism: Breaking functional fixedness
  Your Tool Design: External models see the problem fresh

      569 +## Suggested Next Mode Algorithm
      570 +
      571 +The `suggestedNextMode` in the output guides agents through a
          +productive creative flow. The algorithm:
      572 +
      573 +```typescript
      574 +function suggestNextMode(session: CreativeSession): string | u
          +ndefined {
      575 +  const used = session.modesUsed;
      576 +  const count = session.explorationHistory.length;
      577 +
      578 +  // Natural creative flow: generate → connect → question → co
          +mbine → shift → judge
      579 +  const FLOW = ["diverge", "bisociate", "challenge", "blend",
          +"reframe", "evaluate"];
      580 +
      581 +  // First exploration? Always start divergent.
      582 +  if (count === 0) return "diverge";
      583 +
      584 +  // If we've diverged but haven't bisociated, try bisociation
          + next
      585 +  if (used.has("diverge") && !used.has("bisociate")) return "b
          +isociate";
      586 +
      587 +  // After both diverge and bisociate, challenge assumptions
      588 +  if (used.has("diverge") && used.has("bisociate") && !used.ha
          +s("challenge"))
      589 +    return "challenge";
      590 +
      591 +  // If we have enough raw material (3+ explorations), suggest
          + blending
      592 +  if (count >= 3 && !used.has("blend")) return "blend";
      593 +
      594 +  // If stuck (last 2 explorations produced similar ideas), su
          +ggest reframe
      595 +  if (lastTwoSimilar(session)) return "reframe";
      596 +
      597 +  // If we have 4+ explorations, it's time to evaluate
      598 +  if (count >= 4 && !used.has("evaluate")) return "evaluate";
      599 +
      600 +  // After evaluation, suggest the mode that was rated weakest
      601 +  if (used.has("evaluate")) return weakestAreaMode(session);
      602 +
      603 +  // Default: pick the first unused mode from the flow
      604 +  return FLOW.find(m => !used.has(m));
      605 +}
