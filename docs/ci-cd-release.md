# CI/CD and Release

## Scope

Release pipeline for `iatf` and `iatf-lsp` artifacts.

## Source of Truth

- Workflow: `.github/workflows/release.yml`
- GoReleaser config: `.goreleaser.yml`

## Trigger Modes

- Tag push matching `v*` (release)
- Manual workflow dispatch (release)

## Produced Artifacts

- `iatf` binaries
- `iatf-lsp` binaries
- installer scripts
- checksums (`SHA256SUMS`)
- autogenerated changelog

## Pre-Release Checklist

1. Ensure working tree is clean.
2. Run tests:
   ```bash
   cd go && go test ./...
   ```
3. Validate key fixtures:
   ```bash
   ./iatf validate examples/incident-playbook.iatf
   ```
4. If installer files changed, verify installer flow on at least one target OS.

## Release Steps

1. Commit changes.
2. Create and push a semver tag:
   ```bash
   git tag vX.Y.Z
   git push origin vX.Y.Z
   ```
3. Confirm GitHub release workflow succeeds.
4. Verify uploaded binaries and checksums in the GitHub release.

## Local Dry Run

```bash
goreleaser release --snapshot --clean
```

Use dry runs for packaging verification only; final release artifacts are produced by CI.
